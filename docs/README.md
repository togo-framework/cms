# cms — docs

Lightweight headless CMS for togo: content types, entries, pages, menus, draft/publish.

- **Install:** `togo install togo-framework/cms`
- **Marketplace:** https://to-go.dev/plugins/cms
- **Source:** https://github.com/togo-framework/cms

See [usage.md](usage.md) for the Go API + REST endpoints.
